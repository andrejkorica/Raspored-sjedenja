# Upute za rad na projektu

- Odgovaraj kratko i na hrvatskom.
- React logika i komponente nalaze se samo u `src/main.jsx`.
- `src/grid.css` sadrži isključivo pravila za grid i raspored stolica; `src/style.css` sadrži sav ostali izgled.
- SQLite API je u `server.js`; baza `ucionice.sqlite` nastaje automatski i ne ulazi u Git.
- Prije promjene pročitaj samo datoteke relevantne za zadatak. Za provjeru koristi `npm run build`; ne dodaj nepotrebne testove ili datoteke.
